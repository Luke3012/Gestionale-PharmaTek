# Moduli funzionali (frontend)

Ogni sottocartella è un modulo funzionale dell'applicazione.

- `anagrafiche/` — agenti, medici, clienti, prodotti+categorie, conti, corrieri, listino/prezzi (FASE 1)
- `giornaliero/` — registrazione e gestione ordini, stati, ricerca/filtri (FASE 1)
- `contabilita/` — pagamenti, stati pagamento, saldo corriere, rimborsi (FASE 3)
- `spedizioni/` — export CORRIERE_B/CORRIERE_A, diagnostica (FASE 4)
- `produzione/` — export Laboratorio, stato produzione, keriba (FASE 5)
- `crm/` — note/conversazioni, promemoria, notifiche (FASE 6)
- `shared/` — UI kit, hook condivisi (stato), utilità
