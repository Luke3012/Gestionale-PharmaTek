# Profilo dimostrativo

La demo parte senza anagrafiche operative. Contrassegno e Assegno sono le sole primitive di pagamento predefinite; prodotti e tassonomia restano disponibili con importi pari a zero e codici fornitore vuoti.

Per provare i flussi si possono creare manualmente record con questi nomi:

- `Cliente Demo 001`
- `Agente Demo 001`
- `Medico Demo 001`
- `Paziente Demo 001`
- `Corriere Demo 001`
- `Conto Demo 001`

Non usare dati reali nelle acquisizioni destinate alla documentazione. Il dataset documentale non include recapiti, coordinate bancarie o identificativi fiscali validi.

## Aggiornamenti

L'app consulta il manifest pubblico `releases/latest/download/latest.json` e scarica gli asset senza credenziali. La firma della demo è distinta da quella dell'applicazione operativa; la chiave privata è conservata fuori dai repository.

## Stato legale

Il codice è pubblicamente visibile, ma non è accompagnato da una licenza d'uso.
